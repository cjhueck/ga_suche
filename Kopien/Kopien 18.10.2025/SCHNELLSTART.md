## 🚀 Drei Hauptfunktionen

```
┌─────────────────┬──────────────────┬─────────────────────┐
│   📚 TEXTE      │   🔍 SUCHE       │   🤖 THEMATISCH     │
├─────────────────┼──────────────────┼─────────────────────┤
│ GA-Bände        │ Stichwortsuche   │ KI-Fragen          │
│ durchblättern   │ (intelligent)    │ (semantisch)       │
└─────────────────┴──────────────────┴─────────────────────┘
```

---

## 📚 Tab "TEXTE"

**Schnell erklärt**: Wie ein digitales Bücherregal

```
1. [Filter wählen] → GA-Band oder Jahr
2. [Band anklicken] → Alle Vorträge sehen
3. [Vortrag anklicken] → Volltext lesen
```

**Tipp**: Zusammenfassungen erscheinen automatisch (wenn vorhanden)

---

## 🔍 Tab "SUCHE"

### Einzelwort
```
Feld 1: karma
        ↓
Findet: "Karma", "Karmaentwicklung", etc.
```

### Zwei Wörter
```
Feld 1: karma
Feld 2: seele
        ↓
Findet: Beide Wörter innerhalb 2 Absätzen
        (Intelligente Relevanz-Bewertung)
```

### Exakte Phrase
```
Feld 1: "geistige welt"
        ↓
Findet: NUR exakte Phrase "geistige Welt"
```

### Relevanz-Filter

```
🟩 Hoch    → Sehr relevant (häufig + nah beieinander)
🟧 Mittel  → Moderat relevant
🟨 Niedrig → Weniger relevant
```

**Tipp**: Bei vielen Treffern → "Hoch" wählen!

---

## 🤖 Tab "THEMATISCH"

**Schnell erklärt**: Stellen Sie Fragen in normaler Sprache

```
Eingabe: "Wie beschreibt Steiner die Ich-Entwicklung?"
         ↓
Claude AI analysiert Texte
         ↓
Antwort + relevante Textstellen
```

**Tiefe wählen**:
- Allgemein = schnell ⚡
- Detailliert = gründlich 🔍
- Umfassend = sehr ausführlich 📚

**Tipp**: Wichtige Begriffe in "Anführungszeichen"!

---

## 💡 5-Sekunden-Tipps

| Wenn Sie... | Dann... |
|-------------|---------|
| 📖 **Lesen wollen** | → Tab "Texte" |
| 🔍 **Begriff suchen** | → Tab "Suche" + 1 Wort |
| 🔗 **Zusammenhang suchen** | → Tab "Suche" + 2 Wörter |
| 🎯 **Exaktes Zitat** | → Tab "Suche" + "phrase" |
| ❓ **Frage haben** | → Tab "Thematisch" |
| 🎚️ **Zu viele Treffer** | → Relevanzfilter "Hoch" 🟩 |
| 📅 **Zeitraum begrenzen** | → Jahre-Filter nutzen |

## ⚠️ Häufige Fehler

### ❌ "Keine Treffer bei 2 Wörtern"
**Grund**: Wörter stehen zu weit auseinander (>2 Absätze)  
**Lösung**: Einzeln suchen oder andere Begriffe probieren

### ❌ "Zu viele Treffer"
**Grund**: Zu allgemeine Begriffe  
**Lösung**: Relevanzfilter "Hoch" 🟩 aktivieren

### ❌ "Phrasensuche findet nichts"
**Grund**: Zu strikte Wortgrenzen  
**Lösung**: Anführungszeichen weglassen

## 🎯 Typische Workflows

### Workflow 1: Schnelle Orientierung
```
1. Tab "Texte" → GA-Band öffnen
2. Zusammenfassung lesen
3. Vortrag anklicken → Volltext
```

### Workflow 2: Gezielte Recherche
```
1. Tab "Suche" → 2 Begriffe eingeben
2. Relevanzfilter "Hoch" 🟩
3. Snippets scannen
4. Interessanten Vortrag öffnen
```

### Workflow 3: Thematische Vertiefung
```
1. Tab "Thematisch" → Frage stellen
2. KI-Antwort lesen
3. Textstellen durchgehen
4. Vortrag im Detail lesen
```

## 🔧 Wichtigste Einstellungen

**Relevanzfilter** (Tab "Suche"):
- `Alle` = zeigt alles
- `Hoch` 🟩 = nur beste Treffer (empfohlen bei vielen Ergebnissen)

**Suchtiefe** (Tab "Thematisch"):
- `Allgemein` = schnell, oberflächlich
- `Umfassend` = langsam, gründlich

**Max. Treffer** (Tab "Thematisch"):
- `20` = Standard, schnell
- `100+` = umfassend, langsamer

## 🆘 Schnelle Problemlösung

| Problem | Lösung |
|---------|--------|
| Keine Treffer | Filter entfernen + Rechtschreibung prüfen |
| Zu viele Treffer | Relevanzfilter "Hoch" 🟩 |
| Suche zu langsam | Weniger Treffer wählen (20 statt 100) |
| Zusammenfassung fehlt | "Generieren" klicken (dauert ~20 Sek.) |
| Seite reagiert nicht | Seite neu laden (F5) |
